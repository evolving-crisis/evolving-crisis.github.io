Shortcuts

  • Esc enter Command mode
  • t return to Typing mode
  • n/b next/previous word
  • N/B (Shift+n/b) queue skipped word(s) for deletion
  • dw immediately deletes the current word
  • D delete queued ranges; q clears them
  • Esc/t return to Typing mode, keeping queued ranges
  • :1234 jump to position 1234, then Enter
  • cw change the current word
  • x delete the character at the caret
  • mw mark or unmark the current word
  • m, then t, then Esc and m mark a passage
  • M mask or unmask the current word
  • :mute / :unmute then Enter change typing sounds
  • :radio off / :radio on then Enter control Radio Chaito
  • i edit the lesson
  • Backspace delete the previous word
  • u undo · r redo
  • type restart to reset
