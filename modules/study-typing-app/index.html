Shortcuts

  • Esc enter Command mode
  • t return to Typing mode
  • n/b next/previous word
  • :1234 jump to position 1234, then Enter
  • mw mark or unmark the current word
  • m, then t, then Esc and m mark a passage
  • M mask or unmask the current word
  • i edit the lesson
  • Backspace delete the previous word
  • dw delete the current word
  • u undo · r redo
  • type restart to reset
